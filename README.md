# AI 발표 슬라이드 (박란하)

학교 발표회용 인터랙티브 웹 슬라이드. 외부 라이브러리 없이 순수 HTML/CSS/JS로 동작합니다.

## 실행 방법

가장 간단하게: `index.html` 파일을 더블클릭해서 브라우저로 엽니다.

> iframe 라이브 데모(7번 슬라이드)나 이미지가 정상 동작하려면 로컬 서버로 여는 것을 권장합니다.
> ```bash
> cd AIppt
> python3 -m http.server 8000
> # 브라우저에서 http://localhost:8000 접속
> ```

## 조작키

| 키 | 동작 |
|----|------|
| → / Space / PageDown | 다음 (단계가 있으면 한 단계씩 전개) |
| ← / PageUp | 이전 슬라이드 |
| Home / End | 처음 / 마지막 슬라이드 |
| F | 풀스크린 켜기/끄기 |
| 마우스 클릭 | 화면 왼쪽 = 이전, 오른쪽 = 다음 |

발표 팁: AI란/머신러닝/관심 이유 슬라이드는 다음 키나 클릭으로 내용이 **한 단계씩** 나타납니다. 생성형 AI 슬라이드는 "패턴 학습 보기" 버튼을 누르면 점들이 패턴으로 모입니다.

## 슬라이드 구성 (총 9장)
1. 표지 — "AI" + 발표자
2. AI란? (클릭하면 펼쳐지는 도식)
3. 머신러닝 (3단계 전개)
4. 생성형 AI (호버 카드 + 패턴 학습 데모)
5. 내가 AI에 관심 갖게 된 이유 (5단계 흐름도)
6. 내가 만든 것들 (쇼케이스 갤러리)
7. 라이브 데모 (iframe 임베드)
8. AI와 함께하는 미래 (정리)
9. 마무리 — 감사합니다

## 내 사이트·게임 끼워넣기

### 1) 쇼케이스 카드 (6번 슬라이드)
`index.html` 에서 `▼▼▼ 여기에 스크린샷 ... ▼▼▼` 주석을 찾으세요.
- 스크린샷 이미지를 `assets/images/` 에 넣습니다.
- 카드 안의 `<!-- <img ...> -->` 주석을 풀고 경로를 맞춥니다.
- `data-link="#"` 의 `#` 를 실제 사이트/게임 주소로 바꾸면 카드 클릭 시 새 탭으로 열립니다.
- 제목(`<b>`)과 설명(`<small>`)도 수정하세요. 카드는 블록을 복사해 더 추가할 수 있습니다.

### 2) 라이브 iframe (7번 슬라이드)
`index.html` 에서 `id="liveFrame"` 인 `<iframe>` 을 찾아 `src=""` 안에 사이트 주소를 넣으세요.
```html
<iframe class="live-frame" id="liveFrame" src="https://내사이트주소" ...></iframe>
```
주소를 넣으면 안내 화면이 자동으로 사라집니다.
> 일부 사이트는 보안 정책(X-Frame-Options)으로 iframe 임베드를 차단합니다. 그런 경우 6번 쇼케이스 카드 링크로 새 탭에서 보여주세요.
